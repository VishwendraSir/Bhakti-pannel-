SCIENCE CENTRE LEARNING HUB — Ramayan Interactive Panel
========================================================

START:
1. Keep index.html and the assets folder together.
2. Open index.html in Chrome to test locally.
3. For website hosting, upload BOTH index.html and the entire assets folder (Netlify Drop/GitHub Pages or your hosting file manager).
4. Do not upload only index.html: the included bhajan tracks are stored in assets/.

BHajan controls:
- Select one of the 8 included tracks and press Play.
- Use “भविष्य में नया भजन जोड़ें” to add audio files to the current browser session.
- Files added with the picker are temporary for that open page. To make them permanently available to all visitors, upload those files to the website's hosting and add their paths/options to index.html.
- Browser autoplay restrictions may require a user tap on Play.

IMPORTANT:
Check each track's current license and attribution requirements before publishing it publicly or using it commercially. The HTML does not automatically verify music licenses.

UPDATE: Question-specific explanations and learning facts have been improved to avoid merely repeating the answer. Review content for your preferred Ramayana tradition before public use.
